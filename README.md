# tyrbujac.com

Personal site and blog. Built in pure HTML and CSS — no framework, no build step.

Live at [tyrbujac.com](https://tyrbujac.com).

## Run locally

```bash
git clone https://github.com/tyrbujac/tyrbujac-com.git
cd tyrbujac-com
```

Open `index.html` in a browser, or use a live-reload tool like VS Code's Live Server extension.

## Structure

```
.
├── index.html       Homepage
├── styles.css       All styles
├── posts/           Blog posts
└── assets/          Images
```

## Stack

- HTML, CSS
- Hosted on Netlify
